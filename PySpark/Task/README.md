# PySpark Task: DDoS Attack Detection Data Transformation
All the tasks are done in the 'Task.py' file. Tasks 1 to 9 are implemented sequentially in the 'data_transformation' function. The main function reads the dataset, applies the transformations, and writes the output to a new CSV file partitioned by IP address. 


Some Notes: atk task 4 i computed histograms in 2 ways using pyspark and matplotlib just to try pyspark functionality even though to plot the result was more complicated by this method so i used just matplotlib and the resulted images are in foled images, interesting to analyze, seems that 192.168.10.15 and 192.168.2.133 might be hackers. 


In task 6 i had to troubleshoot a little the mapping to countries because i use all cores and the mapping was not working properly but i fixed it by using a broadcast variable. In task 7 i computed the percentage of zeros in each numeric column and then decided to drop columns with more than 99.7% zeros which resulted in dropping 9% of the columns(no better result for this dataset). 


Finally in task 9 i wrote the resulting dataframe to a csv file partitioned by IP address. For task 10 i made the program pandas_transform_all.py that perform the same transformations using pandas but only for ip 1.0.176.98 and then i compared the execution time of both programs and the results, seems like everything was done right.
